# 003 为参考项目补充中文注释与 C++ 机制教学

## 问题

参考红黑树实现算法完整，但默认读者已经掌握类模板、依赖类型、友元、显式构造、运算符重载、条件编译和测试宏。对于从零学习者，陌生语法与红黑树算法叠加后，无法判断一行代码究竟在处理类型、访问权限还是树结构。原英文注释也多为动作描述，没有充分解释设计动机、状态变化和可移植性限制。

## 形态分析

核心源码约八百行，测试约九百行，规模不算大但概念密度高。若逐行添加“把右孩子赋给变量”式注释，会增大阅读噪声，仍不能建立整体模型。因此注释以阅读导航、职责边界、状态变量、终止条件和风险标注为主；语言机制另建独立知识章节。

## 对立转化

没有按关键字字典顺序孤立解释，而是从最终使用形式 `RBTree<int>`、`tree.insert` 和迭代器表达式逆推模板与接口设计。删除中的双黑被解释为空间换确定性的状态显式化，同时指出 `(T)0` 对泛型能力的损害。对上游代码只补注释，不借“教学化”名义悄悄更改算法行为。

## 状态设计

源码注释围绕 `root/node/parent/grand/uncle/sibling` 建立可追踪状态；文档增加类型替换表、访问权限说明、调用链、变量变化表、编译命令与分级实验。每个语言机制均按“是什么—为什么使用—本项目是否值得照抄”判断。

## 修改结果

- `rbtree.h`：补充模板头文件模型、依赖类型、封装、迭代器、插入/删除修复、旋转指针顺序、验证器与已知设计限制等中文注释。
- `main.cpp`：补充预处理、宏风险、模板别名、函数指针、lambda、测试结构和非标准/过时写法注释。
- `learning-in-pro/002_cpp_language_mechanisms_in_reference_project.md`：新增不少于 3000 字的项目化教学章节。
- `learning-in-pro/summary.md`：扩展学习路线和文档索引。

## 保留的上游限制

本次没有把 `NULL`、camelCase、`using namespace std;`、变长数组、`random_shuffle` 或 GNU 断言宏改写掉，因为目标是注释和教学，不是重构参考项目。文档与源码已经明确标出这些写法不符合课程代码规范。后续可把“测试设施现代化”作为独立练习，避免语言重构与红黑树算法验证相互干扰。
