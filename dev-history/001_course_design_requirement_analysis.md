# 001 课程设计需求识别与拆解

## 问题来源

项目目录中的 `course_design.jpg` 给出的课程设计题目是：

- 题号：31 Red-Black Tree。
- 目标：认识 Red-Black Tree 结构，并能根据其优点解决实际问题。
- 基本要求：
  - 设计并实现 Red-Black Tree 的 ADT。
  - ADT 包括 Tree 的组织存储，以及初始化、查找、插入、删除等基本操作。
  - 分析基本操作的时间复杂性。
  - 实现 Red-Black Tree ADT 的基本操作演示，要求应用图形界面。
  - 演示实例为依次插入 `A L G O R I T H M`，并依同样次序删除。
  - 实现提示：考虑树的旋转。

## 第一轮判断

这个课设的核心不是普通二叉搜索树，而是带颜色约束和旋转修复的平衡二叉搜索树。最容易出错的点不是查找，而是：

1. 插入后如何修复连续红色节点。
2. 删除黑色节点后如何处理黑高亏损。
3. 空叶子 NIL 节点是否显式建模。
4. 图形界面如何展示颜色、父子关系、旋转变化。
5. 删除演示时如何保证每一步后的树仍满足红黑树性质。

## 暂定推进路线

1. 先实现普通二叉搜索树插入、查找和中序遍历。
2. 引入颜色字段、父指针和 NIL 叶子概念。
3. 实现左旋、右旋，并用小例子验证指针关系。
4. 实现红黑树插入修复。
5. 实现删除前先写移植、最小值、查找辅助函数。
6. 实现红黑树删除修复。
7. 做控制台演示与日志输出。
8. 最后再考虑图形界面或可视化展示。

## 关键约束

之后所有 C++ 代码必须遵守：

- Allman 大括号风格。
- 变量名、函数名、文件名使用 snake_case。
- 显式使用 `std::`，不写 `using namespace std;`。
- 先讲清楚思路，再写代码。
