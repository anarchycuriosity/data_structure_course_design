# 004 降低 C++ 语法教学文档阅读门槛

## 问题

用户反馈当前 C++ 语法教学文档仍然有阅读门槛。用户的 C++ 进度主要停留在面向对象基础阶段：了解构造函数、析构函数、重载和重写，但这些知识也尚未完全牢固。因此上一版直接围绕模板、依赖类型、迭代器和编译链接展开，容易让读者在尚未建立前置概念时就被术语密度压住。

## 形态分析

问题不是文档长度不够，也不是知识点缺失，而是学习入口不匹配。原 `002` 更像“参考源码机制索引”，适合已经能接受模板语境的读者；但当前读者需要的是“从已知面向对象知识过渡到模板语法”的桥接层。

## 对立转化

没有继续加深原进阶文档，而是新增一篇更低门槛的桥接文档。讲解顺序从用户已学过的构造函数、析构函数、重载出发，逐步解释 `template <typename T>`、`explicit`、`inline`、第二种 `typename`、`friend` 和运算符重载。这样避免一开始就把多个陌生概念叠在一行源码里解释。

## 状态设计

新文档将阅读状态拆成对象层、封装层、泛型层、安全层、编译层和遍历层。读者可以先掌握对象层、封装层、泛型层，再回到进阶文档。`summary.md` 同步调整索引，明确建议先读 `003`，再读 `002`。

## 修改结果

- 新增 `learning-in-pro/003_cpp_syntax_bridge_from_oop_to_template.md`：从面向对象基础过渡到模板的零门槛桥接文档。
- 更新 `learning-in-pro/summary.md`：调整学习路线和文档索引，避免读者直接进入高密度进阶文档。

## 后续建议

后续如果继续学习参考项目，建议先完成 `simple_box_lab` 小练习，再读 `RBTree<T>`。不要急着同时理解模板、迭代器和红黑树删除修复，否则认知负载会过高。
